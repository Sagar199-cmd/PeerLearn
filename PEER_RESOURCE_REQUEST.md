# Peer Resource Request

## Proposed Feature

Students can post a request for learning resources on a specific topic so that peers can recommend suitable notes, PPTs, videos, or other learning materials.

## User Story

As a student, I want to post a request for learning resources on a specific topic so that peers can recommend suitable resources.

## Expected Flow

1. Student selects or enters a topic.
2. Student describes the learning requirement.
3. Student submits the request.
4. Peers view the open request.
5. Peers recommend suitable resources.
6. Student reviews the recommendations.

## Acceptance Criteria

- A student can create a request with a topic and description.
- The request is visible to peers.
- A peer can recommend a learning resource.
- The student can view the received recommendation.
